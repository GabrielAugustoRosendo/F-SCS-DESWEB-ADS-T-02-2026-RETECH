## 4. Comparação e justificativa
Para um front-end estático que consome Supabase, Vercel, Netlify e Cloudflare Pages são alternativas práticas porque o deploy pode ocorrer sem manter um servidor tradicional. A equipe informa que usa Vercel; confirme essa escolha no painel antes de apresentá-la como publicação ativa. A Railway é incluída como comparação, mas não é necessária para servir o front-end estático atual.

Um domínio próprio pode melhorar a identidade e facilitar a divulgação, mas não é indispensável para a demonstração acadêmica. A URL e o HTTPS precisam ser confirmados no deploy antes de afirmar que o site está publicamente disponível.
